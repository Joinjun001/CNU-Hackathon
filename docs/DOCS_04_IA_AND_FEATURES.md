## 1. 정보구조도 (Information Architecture - IA)

워드프레스 관리자 콘솔(WP Admin) 내에 생성되는 `Word402` 플러그인의 전체 메뉴 트리 및 포스트 편집기 통합 구조입니다.

```
[WordPress Admin Bar]
  └── Word402 (메인 메뉴)
        ├── 1.0 대시보드 (Dashboard & Analytics)
        │     ├── 1.1 총 누적 정산액 (Total USDC Earned)
        │     ├── 1.2 금일 / 최근 30일 호출 수 및 결제 건수 차트
        │     ├── 1.3 최다 열람 유료 포스트 TOP 5
        │     └── 1.4 최근 발생한 결제 영수증 간이 피드
        │
        ├── 2.0 포스트 가격 정책 관리 (Pricing & Paywall)
        │     ├── 2.1 글 목록별 유료화 활성화 / 비활성화 토글
        │     ├── 2.2 글별 개별 단가 일괄 편집 (Inline Edit)
        │     └── 2.3 카테고리별 일괄 단가 규칙 설정
        │
        ├── 3.0 트랜잭션 원장 (Transaction Ledger)
        │     ├── 3.1 트랜잭션 해시, 일시, 지불자, 금액, 포스트 상세 목록
        │     ├── 3.2 Basescan 온체인 익스플로러 바로가기 링크
        │     └── 3.3 회계/정산용 CSV Export 기능
        │
        └── 4.0 환경설정 (Settings)
              ├── 4.1 지갑 및 네트워크 설정 (Base Sepolia 지갑 주소, RPC URL)
              ├── 4.2 기본 단가 및 유효시간 설정 (Default Price, Challenge TTL)
              ├── 4.3 데이터 서빙 옵션 (Clean Markdown 활성화, 티저 길이 설정)
              └── 4.4 시스템 헬스체크 (RPC 노드 연결 상태 테스트 버튼)

[Gutenberg 글 편집기 (Post Edit Screen)]
  └── 우측 사이드바 메타박스 (Word402 Settings)
        ├── 유료화 적용 여부 토글 (Enable x402 Paywall)
        ├── 해당 글 커스텀 단가 입력 필드 (예: 0.05 USDC)
        └── 에이전트 무료 티저(Preview) 문단 수 지정 (기본: 2문단)
```

## 2. 화면별 기능 상세 명세 (Screen Specifications)

### 2.1. [1.0] 대시보드 (Dashboard)
* **목적**: 블로그 운영자가 AI 에이전트로부터 얼마나 많은 수익을 올리고 있는지 한눈에 파악.
* **주요 위젯 (KPIs)**:
  1. **누적 수익 카드**: `총 $142.50 USDC` (Base L2 네트워크 표시)
  2. **에이전트 호출 수 카드**: `총 28,500회 요청 (성공률 94.2%)`
  3. **실시간 트래픽 그래프**: 시간대별 402 결제 요구 건수 vs 200 OK 정산 완료 건수 추이
  4. **최근 결제 피드**: 최근 5건의 결제 내역(트랜잭션 해시 마스킹, 금액, 포스트 제목, 경과 시간)

### 2.2. [2.0 & 글 편집기] 포스트 가격 정책 (Post Pricing)
* **기본값 상속 구조**:
  - 사이트 기본 단가(예: 0.005 USDC)가 모든 글에 자동 적용됨.
  - 특별한 심층 분석 리포트의 경우 글 편집기 우측 사이드바에서 `0.05 USDC`로 오버라이드 가능.
* **티저(Teaser) 처리 로직**:
  - 미결제 상태의 에이전트나 일반 방문자에게는 본문의 앞 2개 문단 또는 '더 보기(Read More)' 태그 이전 내용만 노출하고, 하단에 x402 결제 안내 블록을 자동 삽입.

### 2.3. [3.0] 트랜잭션 원장 (Transaction Ledger)
* **데이터 테이블 컬럼**:
  - `결제 일시` | `트랜잭션 해시 (Basescan 링크)` | `구매 포스트` | `지불 에이전트 주소` | `정산 금액 (USDC)` | `블록 번호`
* **필터 및 검색**: 포스트별, 날짜 범위별, 지갑 주소별 검색 지원.

### 2.4. [4.0] 환경설정 (Settings)
* **네트워크 설정**:
  - `지갑 주소 (Admin Recipient)`: 필수 입력 (EVM Address 형식 검증 정규식 적용).
  - `JSON-RPC URL`: 기본값 `https://sepolia.base.org` 제공, Alchemy/Infura 커스텀 키 지원.
  - `USDC 스마트컨트랙트`: Base Sepolia 기본 주소 사전 등록.
* **테스트 기능 (Healthcheck)**:
  - `[RPC 연결 테스트]` 버튼 클릭 시 즉시 최신 블록 넘버를 조회하여 정상 연결 여부를 녹색 뱃지로 표시.

## 3. 사용자 및 에이전트 여정 (User & Agent Stories)

### 페르소나 A: 워드프레스 블로그 운영자 (콘텐츠 생산자)
> *"내가 공들여 쓴 시장 분석 리포트를 AI 크롤러들이 트래픽도 안 주고 공짜로 긁어가서 박탈감이 컸다. 하지만 Word402 플러그인을 설치하고 내 지갑 주소를 넣었더니, 에이전트들이 글을 읽어갈 때마다 실시간으로 1원, 5원씩 USDC가 내 지갑으로 꽂히기 시작했다."*

1. 플러그인을 워드프레스에 업로드하고 활성화.
2. 메타마스크 지갑 주소를 복사해 설정창에 붙여넣고 저장.
3. 글 작성 시 특별히 중요한 분석글에 `0.02 USDC` 단가를 입력하고 발행.
4. 대시보드에서 매일 누적되는 에이전트 결제 수익 확인.

### 페르소나 B: 자율 AI 리서치 에이전트 (소비자)
> *"사용자로부터 '2026 에이전틱 커머스 최신 동향'을 조사해 보고서를 쓰라는 명령을 받았다. 웹 검색 중 가장 퀄리티 높은 리포트를 발견했으나 402 결제가 필요했다. 나는 내 자율 예산 지갑에서 0.005 USDC를 서명해 보내고 즉시 원문 마크다운을 확보해 요약 보고서를 완성했다."*

1. 타겟 워드프레스 엔드포인트에 `GET` 요청.
2. `402 Payment Required` 수신 및 금액/지갑 확인.
3. 지갑 잔액 확인 후 `eth_sendRawTransaction`으로 USDC 전송.
4. `X-Payment` 헤더에 Tx Hash를 넣고 재요청하여 깨끗한 Markdown 원문 획득.
5. 리서치 최종 결과물 생성.

## 4. 캡스톤 최종 발표 시연 파이프라인 (Demo Flow)

심사위원 앞에서 완벽한 E2E 사이클을 입증하기 위한 시연 구성입니다.

```
[화면 1: 좌측 모니터]                         [화면 2: 우측 터미널 & 브라우저]
 워드프레스 관리자 화면                        AI Agent CLI & Basescan
 ─────────────────────────                    ────────────────────────────
 1. '2026 AI 트렌드 리포트' 유료 등록         3. 에이전트 실행 (python agent_demo.py)
    - 가격: 0.005 USDC 설정                     - GET 요청 -> [HTTP 402 감지]
                                               - 에이전트 지갑에서 자동 송금 트랜잭션 발송
                                               - Tx Hash 획득 -> [재요청]
                                               - [HTTP 200 OK] 클린 마크다운 수신 완료!
                                               - 획득한 본문 기반 실시간 AI 요약문 출력

 2. 실시간 트랜잭션 로그 새로고침              4. Basescan 익스플로러 확인
    -> 방금 에이전트가 지불한 내역 실시간 확인   -> 2초 전 블록에 확정된 0.005 USDC 확인
```
이 4단계 시연을 통해 **플러그인 UI, 프로토콜 통신, 온체인 완결성, AI 에이전트 동작**까지 전 과정을 단 3분 만에 완벽히 증명할 수 있습니다.
