Autonomous AI Agent Monetization Gateway for WordPress via x402 Protocol & Base L2 Micropayments.

== Description ==

Word402 transforms any WordPress website into an autonomous, paid data marketplace for AI agents. 
Instead of blocking AI crawlers with robots.txt, Word402 serves clean Markdown data while automatically charging AI agents per request via the HTTP 402 Payment Required standard and Base Sepolia L2 (USDC).

== Installation ==

1. Upload the `word402` folder to the `/wp-content/plugins/` directory.
2. Activate the plugin through the 'Plugins' menu in WordPress.
3. Navigate to `Word402 -> 환경설정` in your admin dashboard.
4. Enter your Base Sepolia wallet address where USDC payments will be settled.
5. Save settings! Your posts are now monetized for autonomous AI agents.
